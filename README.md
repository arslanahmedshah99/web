# FixCampus\n\nA React + Vite campus issue tracking demo application. This repository includes a login/register UI and an interactive dashboard for reporting campus maintenance issues.\n\n## Run locally\n\n1. Install dependencies: 
pm install\n2. Start dev server: 
pm run dev\n3. Open the URL shown in the terminal\n\n## Demo accounts\n\n- student@campus.ac.uk / student123\n- staff@campus.ac.uk / staff123\n- admin@campus.ac.uk / admin123\n\n## Notes\n\n- 
ode_modules/ and .vite/ are ignored.\n- The app uses echarts for charts and localStorage for demo authentication.\n
